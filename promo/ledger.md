# Ledger

## Раунд 0 — раскадровка
Критик: «one more pass». Принято и сделано в storyboard v2:
- UI мелкий (телефон 26% ширины) → телефон ×2.4, экран 989 px = 52% кадра, камера по областям; полностью виден только в «Теме» (×1.95).
- Приватность на 75% ролика → перенесена на 8.5–11.5 (33–44%).
- Монетка меняла роль → одна роль «палец», исключения: падение и финальная иконка; якорь — центр кадра.
- Эпизод отмены нечитаем → три удара по ≥0.8 с: удалить → тост → вернулось.
- Подписи вне facts («за секунды», «Всё видно сразу») → заменены формулировками из facts.
- 42% как обещание → пометка «пример» 32 px.
- Длина 30 → 26 с: без пустой выдержки.
Отклонено: «плашки утекают в ячейки таблицы» (4) — между приватностью и таблицей теперь динамика; стык идёт через якорь монетки.

## Сборка, до критиков (самопроверка по контактным листам)
- Сумма серая (правило `.amount-field span` приложения) → цвет текста задан явно.
- Первый кадр — белое поле → база телефона = тёмное стекло, волны открывают минимализм и светлое стекло.
- В «Отмене» строки уходили выше кадра → удаляемая строка — в нижней карточке дня, вид ×2.4 охватывает строки, панель и тост.
- Наложения подписей на телефон (План, Отмена, Тема, Переезд) и стыки 8.5 / 11.5 / 14.4 → кегли, позиции, времена разведены.
- Детекция битов: онсеты НЧ, 39/39 бочек, медиана 1.3 мс, максимум 1.7 мс.
- Громкость: −12.7 LUFS → цель loudnorm −14.6 (цепочка добавляет ~0.6 LU).
