# Публикация в Google Play

Рабочий чек-лист. Тексты карточки, иконка, баннер и скриншоты лежат в `fastlane/metadata/android/` (формат fastlane
supply; тот же каталог понимает F-Droid). Исходники картинок — `store/icon.html`, `store/feature.html`, скриншоты
снимаются с `npm run dev` по адресу `/?demo&tab=overview&style=glass&theme=dark` (параметры: `tab`, `style`, `theme`).

## 1. Аккаунт

- Play Console, личный аккаунт разработчика: разовый взнос $25, проверка личности.
- **Новые личные аккаунты:** перед выходом в прод нужно закрытое тестирование — **не меньше 12 тестировщиков,
  14 дней подряд**. Собрать их заранее: друзья, чат, тред на 4PDA/Reddit. Без этого кнопка «в продакшн» не откроется.

## 2. Подпись

Сейчас релизы GitHub подписаны ключом из секретов репозитория (`ANDROID_KEYSTORE_*`). Два пути:

| Вариант | Что будет |
| --- | --- |
| **Play App Signing с этим же ключом** (Console → *Use existing app signing key*, утилита PEPK) | Сборки из Play и с GitHub ставятся друг поверх друга, данные сохраняются. Ключ должен быть сильным: текущий создан как отладочный (пароль `android`) — для Play лучше выпустить новый и начать с ним. |
| **Ключ генерирует Google** (по умолчанию), мы загружаем upload key | Проще и безопаснее, но APK с GitHub и версия из Play — разные подписи: переход между ними только через удаление (сначала резервная копия в приложении). |

Рекомендация: новый сильный upload key (`keytool -genkeypair ... -keysize 4096`), ключ приложения отдаёт Google,
в README честно написать, что GitHub-сборки и Play-сборки не обновляют друг друга.

## 3. Сборка

- CI на каждый push в `main` кладёт в релиз `Monetka-N.aab` — его и загружать в Play.
- `versionCode` = номер прогона CI, растёт сам. `versionName` = `1.1.N`.
- `targetSdk 36`, `minSdk 24` — проходит требования Play на 2026 год.

## 5. Анкеты Play Console

- **Безопасность данных (Data safety):** «Приложение не собирает и не передаёт данные пользователей» — да.
  Шифрование при передаче — не применимо (нет передачи). Удаление данных — через удаление приложения.
- **Доступ к приложению:** все функции доступны без входа.
- **Реклама:** нет.
- **Возрастной рейтинг (IARC):** категория «Утилиты/продуктивность», на все вопросы о насилии, азартных играх и
  общении — нет. Финансовый учёт без операций с деньгами не считается «финансовыми услугами».
- **Целевая аудитория:** 18+ (не детское приложение — меньше требований).
- **Финансовые функции (Financial features declaration):** «Приложение не предоставляет финансовых услуг»,
  отметить только «учёт личных финансов / бюджет».
- **Правительственное приложение, новости, медицинское:** нет.
